## Shape of Dreams はコントローラーに対応している？

はい。PC 版はネイティブのゲームパッド対応を備えており、互換レイヤーを経由せずにゲームがコントローラーを直接読み取ります。Xbox 系の XInput パッドが最もスムーズな体験ですが、PlayStation のコントローラー、Switch Pro パッド、そしてほとんどの最新サードパーティ製ゲームパッドも同様に動作します。

戦闘はツインスティック風のループ — 一方の入力で移動し、もう一方でアビリティを狙う — を中心に構築されているため、コントローラーはこのジャンルに最も自然に合うと言えるでしょう。4 方向ではなく 8 方向のアナログ移動が得られ、アビリティボタンはキーボード全体に散らばるのではなく、両親指の下に収まります。

| デバイス／プラットフォーム | コントローラー対応 | 備考 |
|---|---|---|
| Windows PC（Steam） | ネイティブ | XInput パッドを自動検出 |
| Steam Deck | ネイティブ | 携帯モードの操作に加え、ドック接続のゲームパッドも対応 |
| Xbox ワイヤレス コントローラー | 最適 | デフォルト配置に最も近い |
| DualSense / DualShock 4 | 非常に良好 | 振動は動作。ハプティクスはビルドによって差あり |
| Switch Pro コントローラー | 良好 | Steam Input の有効化が必要な場合あり |
| サードパーティ製 XInput パッド | 良好 | 8BitDo など同系統ブランドは概ね問題なし |
| 汎用 DirectInput パッド | まちまち | 再割り当てが必要になることが多い |

パッドがゲーム内に表示されない場合、原因はゲーム本体ではなく、Steam Input が信号を横取りしていることであることがほとんどです。詳細はトラブルシューティングのセクションで扱います。

## Shape of Dreams コントローラーのデフォルト配置

正確な割り当ては再設定できますが、初期状態の配置は標準的なアクションローグライクの慣習に従っています。パッドを初めて接続したときに想定すべき典型的な構成は以下のとおりです。

| 入力 | アクション | 重要な理由 |
|---|---|---|
| 左スティック | 移動 | アナログ移動は飛び交う弾をかわすのに役立つ |
| 右スティック | エイム | 移動とは独立してアビリティを撃てる |
| 右トリガー | 通常攻撃 | 戦闘中は常に押し続ける |
| 左トリガー | 主要アビリティ | 主力のダメージまたはユーティリティスキル |
| フェイスボタン | サブアビリティ | クールダウン制のスキルとアルティメット |
| ショルダーボタン | ダッシュ／回避 | ゲーム内で最も重要な単一ボタン |
| D パッド | 消耗品、パーティアクション | メニューを開かずに素早くアクセス |
| Start / Menu | ポーズと設定 | 部屋間のビルドメニューでも使用 |
| View / Select | マップまたはパーティ情報 | 協力プレイで便利 |

コミュニティの報告でよくある不満は、変則的なボタン形状のサードパーティ製パッドではダッシュが扱いにくい位置にあるというものです。心当たりがあるなら、グリップを握り替えずに押せるバンパーやトリガーにダッシュを再割り当てしましょう。

### 感度とデッドゾーンの調整

初期設定では、高速なローグライクにおいてほとんどのパッドがやや鈍く感じられます。以下はあくまで出発点の提案であり、ゲーム内のデフォルト値ではありません — 好みに合わせて調整してください。

| 設定 | 推奨の開始値 | 変わるもの |
|---|---|---|
| エイム感度 | 中〜高 | エイムの照準がスティックに追従する速さ |
| デッドゾーン | 低め、10 パーセント前後 | 入力が認識されるまでスティックを倒す必要がある距離 |
| 振動 | オン | 被弾やボスの予備動作に対する有用なフィードバック |
| エイム反転 | オフ | 完全に個人の好み |
| ボタン配置 | カスタム | ダッシュと主要アビリティを優先 |

スティックに触れていないのにキャラクターが動く場合、デッドゾーンが低すぎるか、スティックにドリフトが発生しています。少し上げるだけで、反応性を損なわずに解決できるのが通常です。

## コントローラー vs キーボード＆マウス：どちらを使うべき？

これは多くの操作スレッドを埋め尽くす疑問であり、正直な答えは「どのように狙いたいかによる」です。このゲームにおいて、どちらの入力が明確に優れているということはありません。

| 観点 | ゲームパッド | キーボード＆マウス |
|---|---|---|
| 移動 | 滑らか、アナログ、8 方向以上 | キビキビしているが 4 方向に限定 |
| エイム | 方向ベース、右スティックによる補助 | 精密、カーソルを直接操作 |
| アビリティ操作 | 親指の下のボタン | 素早くアクセス、キー数も豊富 |
| 長時間プレイ | 快適、リラックスした姿勢 | 数時間で手首に負担がかかる |
| ソファでの協力プレイ | 受け渡しが簡単 | 扱いにくい |
| セットアップの手間 | 時々トラブルシューティングが必要 | ほぼ常にプラグアンドプレイ |

ツインスティック系やアクションローグライクをよく遊ぶなら、**Shape of Dreams コントローラー** への移行はほぼシームレスです。MOBA やシューター出身でカーソルの精密な配置に頼るなら、キーボードとマウスのほうがしっくりくるかもしれません。多くのプレイヤーは両方を接続したまま、ランに応じて切り替えています。

## Shape of Dreams コントローラーの設定方法

手順を理詰めで進めれば、セットアップはおよそ 5 分で完了します。手順を飛ばすと、二重入力や「動くけれど何か違う」パッドになってしまうものです。

| 手順 | やること | 役立つ理由 |
|---|---|---|
| 1 | ゲーム起動前にパッドを接続する | 起動時の検出を確実にする |
| 2 | Steam を開き、コントローラーが認識されているか確認する | ドライバーレベルの問題を除外できる |
| 3 | ゲームを起動し、操作メニューを開く | ゲームがデバイスを認識しているか確認 |
| 4 | 安全な場所で移動とエイムを試す | デッドゾーンの問題を早期に発見 |
| 5 | まずダッシュと主要アビリティを再割り当てする | この 2 つの入力が最も重要 |
| 6 | 本番前に短い練習ランを 1 回走る | 低コストで筋肉記憶を形成できる |

いくつかのちょっとした習慣が大きな差を生みます：

- 有線接続か、新しい電池を優先する — ボス戦の途中で Bluetooth が切れるのは地獄です。
- 二重入力が見られる場合は、有効な入力デバイスを 1 つだけにする。
- 最終的な割り当てをメモまたはスクリーンショットで残し、アップデート後に復元できるようにする。
- TV でプレイする場合は、入力遅延を減らすためにディスプレイのゲームモードがオンになっているか確認する。

### コミュニティで報告されているつまずきポイント

プレイヤー体験から見えてくる最も一般的な不満は、Steam Input の競合と、コントローラーブランドによって振動の挙動が異なることの 2 点です。どちらもゲームを壊すものではなく、どちらも簡単な修正方法があります。

## Shape of Dreams コントローラーのよくある問題のトラブルシューティング

パッドが反応しなくなったら、外側から内側へと確認していきます：ケーブルまたは電池、次に Steam、そしてゲームです。ほとんどの問題は Steam のレイヤーで解決します。

| 症状 | 想定される原因 | 修正方法 |
|---|---|---|
| コントローラーが検出されない | Steam Input の競合 | Steam Input をオンまたはオフに切り替えて再起動 |
| 二重入力 | 2 つのデバイスが同時に有効 | 使っていないパッドまたはキーボードを切断 |
| スティックドリフト | ハードウェアの摩耗、または低すぎるデッドゾーン | デッドゾーンを上げるか、パッドを交換 |
| ボタンが何も反応しない | アップデート後に割り当てがリセット | カスタム配置を再適用 |
| ランダムに切断される | Bluetooth 信号が弱い | USB に切り替えるか、レシーバーを移動 |
| 振動しない | ハプティクス非対応 | 設定で標準の振動を有効にする |

それでも解決しない場合は、Steam でゲームファイルを検証し、コントローラーのファームウェアを更新し、別の USB ポートを試してみてください。対応機能や最新のパッチノートについては、[Steam の Shape of Dreams 公式ページ](https://store.steampowered.com/search/?term=Shape+of+Dreams)を確認してください。プラットフォームの詳細について最も信頼できる情報源です。

## 協力プレイ、Steam Deck、アクセシビリティのための応用のコツ

コントローラー対応はソロプレイだけの話ではありません。協力プレイのランでは、各プレイヤーがそれぞれの入力方法を必要とし、**Shape of Dreams コントローラー** があれば、何も再設定せずに友人にパッドを渡せます。

| シナリオ | 推奨構成 | 理由 |
|---|---|---|
| オンライン協力、2 人 | パッド 1 台、マウスとキーボード 1 組 | セットアップが最速 |
| ゲストとのソファプレイ | ワイヤレスパッド 2 台 | 受け渡しが簡単、机も不要 |
| Steam Deck 携帯モード | 内蔵コントローラー | 追加ハードウェア不要 |
| Steam Deck ドック接続 | Bluetooth パッド | Deck を冷えた安定した状態に保てる |
| 身体の可動域に制限のあるプレイヤー | カスタム再割り当て、低デッドゾーン | 手や手首への負担を軽減 |

最後にいくつかのポイント：

- 最もよく使うアビリティはフェイスボタンではなくトリガーに割り当てて、エイムスティックから親指を離さずに済むようにする。
- 消耗品は D パッドに割り当てて、戦闘中にメニューを開かなくて済むようにする。
- ボス戦が不公平に感じるなら、デザインを責める前に感度の変更を試す — わずかなエイム調整で、問題は入力側だったと分かることがよくあります。
- 1 ランにつき 1 つのコンボを自動化できるまで練習する。このゲームにおけるコントローラーの習熟は、理論ではなく筋肉記憶です。

## FAQ

**Shape of Dreams はコントローラーに完全対応していますか？**
はい。PC 版にはネイティブのゲームパッド対応が含まれており、Xbox 系パッドが最もスムーズな体験を提供します。PlayStation、Switch Pro、そしてほとんどのサードパーティ製パッドも動作しますが、一部は再割り当てや Steam Input の有効化が必要になる場合があります。

**Shape of Dreams のコントローラー割り当ては再設定できますか？**
ほとんどのビルドでは可能です — 操作メニューで移動、エイム、攻撃、アビリティを再割り当てできます。コミュニティの報告では、戦闘で最も比重の大きいダッシュと主要アビリティをまず再割り当てすることが勧められています。

**コントローラーがゲームに検出されないのはなぜですか？**
最も一般的な原因は、ハードウェアの不具合ではなく Steam Input の競合です。Steam Input を切り替え、ゲームを再起動し、入力デバイスが 1 つだけ接続されていることを確認してください。問題が続く場合は、ゲームファイルを検証し、コントローラーのファームウェアを更新してください。

**このゲームではコントローラーのほうがキーボードとマウスより優れていますか？**
どちらが明確に優れているということはありません。**Shape of Dreams コントローラー** は滑らかなアナログ移動と長時間でも快適なプレイを提供し、キーボードとマウスはより精密なエイムを可能にします。多くのプレイヤーは両方を接続したまま、ランに応じて切り替えています。

**スティックに触れていないのにキャラクターが動く場合はどうすればいいですか？**
それはスティックドリフト、またはデッドゾーンが低すぎることによるものです。設定でデッドゾーンを少し上げ、それでも問題が続く場合は別のゲームでパッドを試し、ハードウェアが摩耗していないか確認してください。
